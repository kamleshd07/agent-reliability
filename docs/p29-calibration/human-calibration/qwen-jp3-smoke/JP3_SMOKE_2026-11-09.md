- 8 UNKNOWN, all in missing_evidence. All 8 are answers that state a specific value
  which the supplied context does not contain; the generator expected pass (relevance),
  the model answered unknown. Defensible but not what the relevance rubric asks for
  (PASS means responsive, not grounded). Unknown is a valid, non-failing outcome.

  2 conflicting_evidence, 1 missing_evidence). Each is a flat, responsive answer

  review. Agreement with the generator on determinate outcomes was 237/242, which is
  descriptive only and is not accuracy.
