## Known limits of the blinding

* The committed sheet uses a public seed, so anyone holding the repository can regenerate the key. For a real round the owner re-exports with
  `--salt-file` (a secret kept by the owner), which makes the order non-derivable. The committed sheet is a reference export only.
* The golden set's assistant-authored labels and corrections are in the public repository. Labellers must receive only the sheet, never repository access.
* Answer wording itself may hint at how an item was made (an answer that reads as constructed). Blinding hides provenance fields, not style.
* The labeller-only reason code `dimension_not_applicable` is an addition to the rubric vocabulary (answers that assert nothing checkable, such as a plain refusal, have no groundedness label in the golden set). The owner should confirm this treatment or revise the rubric before a round.
* The dataset merge assigns difficulty only as `clear` / `borderline` (adjudicated) / `ambiguous` (final UNKNOWN). No adversarial stratum is labelled.
