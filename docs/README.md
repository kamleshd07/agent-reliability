# Documentation

## Task-first path

Follow these in order for a first integration: [Quickstart](QUICKSTART.md) →
[Integrations](INTEGRATIONS.md) (instrument) → [Evaluate](EVALUATE.md) →
[Measure reliability locally](MEASURE_RELIABILITY_LOCALLY.md) →
[Test reliability](TEST_RELIABILITY.md) → [OpenTelemetry](OTEL_MAPPING.md)
(optional) → [Concepts](CONCEPTS.md) for the terminology behind all of it.

## Getting started

- [Quickstart](QUICKSTART.md): install to first reliability result
- [Core concepts](CONCEPTS.md): terminology without architecture prerequisites
- [Integration guide](INTEGRATIONS.md): sync, async, frameworks, and OTel
- [Evaluate](EVALUATE.md): built-in evaluators, UNKNOWN, and the
  `evaluate_reliability_or_raise` convenience API
- [Measure reliability locally](MEASURE_RELIABILITY_LOCALLY.md): human and
  machine-readable report presentation
- [Test reliability](TEST_RELIABILITY.md): asserting an SLO in your own
  tests or CI
